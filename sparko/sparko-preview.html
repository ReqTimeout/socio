Cara pakai

Import & render

<script>
  import Sparko from '$lib/components/Sparko.svelte';
</script>

<Sparko pose="idle" size={96} />
<Sparko pose="wave" size={48} />
<Sparko pose="celebrate" size={120} />

Props

pose   'idle' | 'wave' | 'celebrate' | 'sad' | 'error' | 'sleep'  (default: 'idle')
size   number (default: 120)
label  string override aria-label

Kapan pakai pose apa

idle       → navbar logo mini, hero default, loading
wave       → HowItWorks step 1, "hallo newbie" CTA
celebrate  → order sukses, signup ok, confetti moment
sad        → saldo 0, empty cart, "kok sepi ya"
error      → 500 page, API error, form gagal submit
sleep      → 404, maintenance mode, "panel istirahat dulu ya"
